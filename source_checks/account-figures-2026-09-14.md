# Latest public company-account figures

Official references: [live API definition](https://data.brreg.no/regnskapsregisteret/regnskap/v3/api-docs) and [dataset description](https://data.norge.no/nb/data-services/4dabc5ea-b57b-3b68-9e48-2ff993be3f6e/nokkeltall-fra-arsregnskapet). The live path is `/regnskapsregisteret/regnskap/{orgNummer}`. An older repository specification uses a different query route and must not be substituted for the live contract.

Two real polls of the final recipe each returned two company accounts: one per configured organization, both covering 2025, with currencies USD and NOK. Both polls produced zero alerts and identical full state. Exact request URLs, sizes, response hashes, configuration and adapter hash are recorded in [the evidence JSON](account-figures-2026-09-14.json). Calls used ordinary TLS and no credentials. The OpenAPI advertises authentication for the wider API; these observed latest-company calls are publicly accessible, which is not proof of access to historical or group accounts.

Stable record identity combines organization, company-account type and both period dates. The source account ID and journal number are monitored fields, so their replacement within the same period changes that record. This does not assert a documented legal revision event. A new period produces a new observation; a regressed period fails without advancing state. Unexpected array size, organization/type mismatch, malformed statement groups, dates, numeric fields, duplicate JSON keys, redirects and oversized responses fail closed. The verified response has exactly one company account; a changed response scope needs inspection.

Numeric JSON is parsed with decimal precision and normalized without binary floating-point conversion. Missing and null fields remain unknown, distinct from actual zero. Monetary scale is not documented in the inspected official schema: values and currency are preserved without multiplying, conversion or financial ratios, and alerts disclose this limitation. Statement totals are retained as reported, not recalculated or forced to balance. The observed first account's assets and equity/liability totals differ; this monitor does not correct the source. Parent-company flags are not used to label company accounts as consolidated figures.

Seven adapter tests cover quiet repeats, figure changes, source-ID replacement, new periods, currency changes, missing/zero distinction, large precise decimals, notation equivalence, period regression, multi-company atomic failure, invalid scope/schema and transport limits. Together with recipe, catalog and test-runtime generation checks, 25 targeted tests passed. Artificial changes prove event logic; no later actual filing/change delivery is established by these two reads. Historical corrections after a period leaves the latest response are outside coverage. No notifier was used for the real-data checks.
