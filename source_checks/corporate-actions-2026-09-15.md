# Derivative corporate-action notice revisions

The official [Euronext derivative notice index](https://live.euronext.com/en/resources/notices-corporate-actions/derivatives-corporate-actions) exposes structured rows with notice identity, notice number, issue date, effective text, event type and instrument text. Each notice also exposes dated PDF attachment metadata. The existing issuer-news adapter does not monitor this contract.

The final recipe reads the first page of 50 rows twice per poll. Two real adapter polls returned 50 records, zero initial alerts, zero repeated alerts and identical complete next state, through four complete HTTP responses. Exact URL, byte count, response hash and code/configuration hashes are recorded in the adjacent JSON. Raw source pages are not included. Forty-eight targeted synthetic contract and integration tests passed; synthetic fixtures are not source evidence.

A separate check of the observed second-page link returned 50 additional identities, no overlap with page one, and an active-page marker of 2. The configurable window supports one to five pages, fixed page size 50. Every fetched page must have the expected derivative form identity, exact headers, matching active page, valid next-page destinations, all expected row containers, unique notice IDs and matching PDF notice/attachment identities. A short nonterminal page, duplicates, redirects, malformed dates, bounds violations or disagreement between two window reads preserves prior state.

The first pages follow the source's ordering. They are not necessarily the most recently issued notices: long-running notices can retain an old issue date while attachments change. Issue date, effective date and attachment date are separate fields. “To be Announced” remains literal text with no effective date. Dates have no inferred time zone. The first read is quiet; subsequent new or changed entries can alert once. Button labels, footer changes and row/attachment ordering do not generate revisions.

This function covers source-labelled events affecting derivatives. It does not read PDFs, lazy details, cash-market purchase links, adjustment ratios, dividend amounts or legal outcomes. A stable PDF URL whose contents change without metadata changes is outside coverage. The archive beyond the configured pages is outside coverage; notices can move across the boundary between polls. Disappearance does not imply cancellation. Local source evidence does not establish scheduled operation or alert delivery.
