# Legal announcement publication and document changes

The official public-data list advertises annual division-I gazette archives. Two list responses contained the same four objects in different order; filenames are canonical identities. Advertised byte counts are strings. The current individual-year package is 2026, with 988 document files: 77 law and 911 regulation records. Older multi-year bundles and consolidated-law packages are outside this adapter.

Two separately retrieved archives were byte-identical. The final recipe also passed two complete actual adapter polls: eight HTTP responses covering two list/archive sweeps each, 988 stored records, zero initial alerts, zero repeat alerts and identical full state. Every file is parsed and validated before selecting document types. The package has 14,843,830 bytes of document payload, with a largest file of 345,334 bytes. Transport, decompressed tar, member count and individual file size have separate bounds. Files are read in memory without extraction. Unsafe paths, links, duplicate members, extended headers, incomplete framing and concatenated compression streams are rejected.

Document ID, legacy ID, internal reference, body identity, filename, year and title must agree. Every observed document has separate source publication text and commencement text. Publication text ranges from `2026-01-05 14:20` to `2026-09-11 14:35`; its timezone is not stated. Commencement may be a date or a phrase such as `Kongen bestemmer`. Neither field establishes legal status or consolidated law. A sampled official document link returned HTTP 200 at its exact derived ID and matched its title.

Monitored changes include title and selected header metadata, normalized document text, image references, table spans, amendment targets and source correction annotations. A checksum is stored for comparison but not shown as a user-facing change description. Formatting-only style changes are excluded. Image files and attachments are not fetched. An unchanged image URL cannot reveal changed image bytes.

The recipe follows the newest advertised single-year package; `latest_years` and `document_types` are configurable. Requested annual packages must be available. A newly advertised year is discovered without inventing a download route, and regression to an older year fails before history is replaced. Earlier years outside the selected packages are not monitored. Missing documents do not establish repeal or withdrawal.

Two consistent sweeps are not a server transaction or independent proof that all legal announcements are present. The targeted tests use artificial documents to exercise new and changed records, repeat suppression, metadata/identity failures, year regression and bounded archive handling. They do not establish actual later delivery. Response and implementation hashes are recorded in the adjacent JSON file.

Document bytes are decoded explicitly as UTF-8 before HTML parsing. All 988 documents passed strict decoding in the final repeated source check. This avoids platform-dependent encoding guesses; malformed byte sequences fail before history changes. Identity errors identify the bounded document ID and disagreeing fields without copying document content.

The source embeds inline formatting tags inside HTML titles. A check using the official CPython 3.12.14 HTML parser on the local Python 3.12.10 interpreter reproduced 17 title disagreements in the earlier comparison, including subscript formatting. The original title fragment is now parsed outside the title RCDATA context; all 988 documents passed with that parser. This is a parser compatibility check, not a complete replica of another operating environment. A regression test also rejects genuinely different formatted titles.
