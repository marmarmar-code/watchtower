# Hydropower registry status and technical values

The [official NVE API contract](https://api.nve.no/doc/vannkraftdatabase/) documents separate full and in-operation plant exports. The final recipe reads both. Two real polls each returned 2,009 full records and 1,863 operating records. Every operating ID and its monitored fields matched the full export exactly. Both polls produced zero alerts and identical full state. The full export includes 106 records marked out of operation and 40 under construction. [Evidence JSON](hydropower-2026-09-14.json) records exact requests, sizes, hashes and final configuration/adapter fingerprints. Calls used ordinary TLS and no notifier.

Stable identity is the source plant number. Names, type, registry status, reported commissioning date/retirement year, geography and technical values are monitored fields. Optional explicit plant IDs narrow the output only after both exports have been validated. An explicitly selected missing ID fails without advancing state. The default recipe observes the full export; source absence never asserts shutdown or deletion. The official export is a single JSON array without a reported total or pagination metadata. The operating cross-check detects inconsistent sets and changed monitored values between reads; it does not independently prove completeness of every non-operating record.

Numeric values retain decimal precision, sign and missing/zero distinctions. Units are maximum output in MW, mean annual generation in GWh/year for the 1991–2020 inflow reference period, gross head in metres, flow capacity in cubic metres/second and energy equivalent in kWh/cubic metre. The current full export contains negative pump values and null technical values, which are retained. These are reported technical attributes, not measured production for the current year. Source dates and retirement years are labelled as reported metadata rather than independently verified event timestamps.

The published register status for out-of-operation plants concerns permanent closure rather than temporary outages. This monitor makes no live availability, incident or actual generation claim. Owner and related personal data are excluded from monitored state and public fixtures. Alerts link to the [official overview](https://www.nve.no/energi/energisystem/vannkraft/oversikt-over-vannkraft/) and include the source plant ID; an individual plant deep link is not claimed.

Seven adapter tests plus recipe/catalog tests passed (25 targeted checks). They cover quiet repeats, reordered exports and ignored ownership changes, new plant IDs, capacity changes, construction/operation/retirement transitions, exact selection, negative/null/zero and precise decimal values, cross-export races, atomic failure, missing schema fields, conflicting flags, invalid dates, duplicate JSON/plant identities, transport and byte/record limits. Artificial changes establish event behavior only. No later actual changed plant record or delivery has yet been observed. The adapter follows one registry function; additional plant IDs or fields do not increase the function count.
