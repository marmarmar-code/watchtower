# Published customs tariff revisions

Two actual reads through the final recipe returned identical 40,976,143-byte JSON resources. Version 1.2 contains 7,440 commodity records; selected chapters 04 and 16 contain 117 commodities and 2,980 rate entries. Both polls produced no alerts, and full state remained identical. Exact response, module and configuration hashes are in the adjacent JSON.

Tolletaten publishes the [official dataset](https://data.toll.no/no/dataset/tollavgiftssats) under CC BY 4.0. It contains tariff rates with country-group codes and validity dates. Each commodity number is a stable monitored identity. Every rate period in the selected commodity is preserved, including future entries. Changing a rate or validity date therefore revises the same commodity. No clock-based activation, inclusive-end-date interpretation, actual payable import duty, currency or country-name inference is made. Source descriptions distinguish percentage of value, per kg, per litre and per piece. Missing/blank units remain unknown. Blank end dates remain unprovided dates.

The entire resource must be downloaded before local chapter selection. It is approximately 41 MB per poll. The recipe runs daily and allows up to 60 MB using `max_tariff_bytes`; this dedicated option has an 80 MB upper bound. Shared limits for other source types are unchanged, and `max_bytes` is rejected here to avoid ambiguity. Downloading streams to a temporary disk file that is always closed. JSON parsing still requires memory for the complete bounded payload. No compressed resource or server-side chapter filter was observed.

Validation checks the envelope, unique eight-digit commodity identities throughout the resource, selected commodity/rate schemas, duplicate groups/periods, nonnegative decimal values, dates, per-commodity rate bounds and presence of every selected chapter. JSON duplicate object fields, redirects, truncated payloads and configured size/count limits fail before state updates. Schema details of unselected rate records are not validated. The source has no independent total-count field, so a syntactically valid but silently partial upstream resource cannot be ruled out merely by parsing. Absence does not establish withdrawal and removal alerts are disabled.

Rate and agreement ordering, and equivalent decimal formatting, do not trigger alerts. Actual changes show earlier and newly listed rate entries without pairing unrelated periods. Artificial tests cover those transitions and malformed/duplicate/incomplete inputs. Hosted initialization, a later scheduled repeat and a real new tariff delivery require separate evidence.
